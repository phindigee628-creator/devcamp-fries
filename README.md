# DevCamp's Fantastic Fries (Learning Project)

A practice website built while learning HTML and CSS. It is **not a real business**. The address, phone number and prices are made up.

**Live site:** https://phindigee628-creator.github.io/devcamp-fries/

**Built with:** HTML and CSS (plus a small JavaScript message on the contact form)

**Pages:** Home, About, Menu, Contact

**What I practised:** multi-page layout, flexbox, CSS grid, hover effects, forms, and a phone-friendly design.
